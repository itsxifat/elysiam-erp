- **RESOLVED**: binding.
- **ASSUMED**: a default that stays in effect until the client answers. Build it behind configuration so it can change without a rewrite.
- **OPEN**: needs an answer before the listed milestone. Until then, use the stated default and keep it configurable.

Changing a RESOLVED row needs the human's approval. When you add a row, put the milestone that created it in the Notes column.
