## Changed on 2026-10-05 (D-581)

  fresh, at `erp.elysium-lifestyle.bd`, as soon as M31, M33, M35a and M38a are joined and

- The mother ERP comes later, on a server the owner names.

## What this is, in plain words

Putting it all on real machines: a brands server running one ERP per brand (Elysium first),
a separate mother server, and the Elysium website switched over to its ERP with its data
moved. Nothing here is done on a live server without the owner's go-ahead for that step.

## Scope

1. **Brands server**: `infra/brand/` (M31) installed; one compose project per brand; nginx site
   and certificate per brand admin host (`admin.elysium-lifestyle.bd` by default); backups per
   brand database (M14b's scripts, per project); the tunnel-only SSH account for the mother.
2. **Mother server**: `infra/mother/` (M32) installed on its own domain; first owner created
   with `pnpm mother:bootstrap`; each brand registered with its read connection and owner-link
   key.
3. **Elysium switch-over runbook** (`docs/runbooks/website-switch-over.md`), in order, with a
   rollback at each step:
   1. freeze the old admin panel (read-only banner), export Mongo;
   2. dry-run the importer, the accountant fills in the cost sheet, commit;
   3. deploy the converted website against the ERP on a staging host and run M36's
      Playwright pass;
   4. switch DNS or nginx for the live site; `/admin` now redirects to the ERP;
   5. point ncom's connector and Steadfast's webhook at the ERP; rebuild the scanner APK;
   6. keep the old database read-only for 30 days, then archive it.
4. **The current test site** (`elyerp.enfinito.cloud`, five brands in one database) is
   replaced by a brand deployment for one demo brand and a mother deployment, both seeded with
   demo data, after the owner confirms (its sign-ins change).

## Owner inputs needed

- Which machine is the brands server and which is the mother server, and the mother's domain.
- DNS for `admin.elysium-lifestyle.bd` (or the address the owner prefers).
- SSLCommerz, SMTP, Meta, GA4 and ncom credentials for Elysium; the accountant's cost sheet.
- A date for the switch-over.

## Acceptance checks

1. Each brand deployment passes its health checks and M31's bundle scan in production.
2. The mother shows Elysium's figures, and "Open Elysium ERP" works.
3. The switch-over runbook is rehearsed end to end on staging, with timings recorded.
