# M06: Catalog

Phase 1 · Effort XHIGH · Depends on: M05 · Architecture §6, §8, §22

## Scope

The `catalog` schema — categories, attributes, products, SKUs as a variant
matrix, barcodes, selling price with history, images — plus the SKU generator,
CSV import, search, and the console screens.

## The one thing this milestone must not do

**No purchase cost anywhere in it.** Invariant 5 says cost lives only in supply,
inventory and the ledger, and check 3 makes that a build gate: no catalog table
or endpoint has a cost column, and `assertNoCostFields` passes for every role.

Selling price is not cost and belongs here. WAC, landed cost and supply line
prices belong to M07 and M09. The failure mode is a well-meaning "cost" column
added for a margin display on a product page, which then reaches a reseller
through the catalog endpoint the allow-list was built for.

`COST_FIELDS` in `packages/contracts/src/permissions/subjects.ts` is frozen by a
test; any cost-shaped column added later must be added there too, and this
milestone is where the habit is set.

## Traps

- **The variant matrix regenerated instead of extended.** Check 1: adding a size
  later creates _only_ the new SKUs. Regenerating drops SKUs that already have
  stock and history behind them, and M07's movements reference them.
- **SKU uniqueness per org, not globally.** Five brands, one database. The
  pattern is per-org (`{ORG}-{CAT}-{SEQ4}-{COLOR}-{SIZE}`) and the sequence is
  per-org, which means the uniqueness constraint is composite — and taking the
  next sequence number under concurrency needs the same care as any counter, not
  a read-then-write.
- **CSV import that half-succeeds.** Check 4: the dry-run reports row-level
  errors and the commit is all-or-nothing. A partial import of a price file
  leaves some SKUs repriced and nobody knows which.
- **Search measured by hand.** Check 2 says `scripts/bench.mjs`, so the method
  matches every other latency check in the project rather than being a stopwatch
  in a comment.

## Assumptions to record

- The SKU pattern's separator and segment widths, since §8 gives an example
  rather than a specification.
- Whether a product may exist with no SKUs (a draft), which the variant matrix
  generator's flow implies but §8 does not state.

## Status on 2026-09-30

Built and integrated on branch `m06-catalog`. Schema `catalog`, migrations 0023
to 0026. 21 routes under `/v1/catalog`. Console screens: products, structure,
price import, new product, product detail.

Check 2, search latency, is measured with `pnpm bench catalog`: p95 of 3.6 to
6.2 ms over 200 samples. The first acceptance audit's gaps were closed with
mutation-tested regressions. A fresh acceptance audit is still owed.
